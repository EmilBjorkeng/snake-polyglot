# snake-polyglot

The game Snake written in different programming languages.

## Languages

| Language | Runs in | Built with |
| --- | --- | --- |
| [Python](python/) | GUI | [pygame](https://www.pygame.org/) |
| [Rust](rust/) | Terminal | [crossterm](https://crates.io/crates/crossterm), [rand](https://crates.io/crates/rand) |

Each folder has its own README with instructions for running that version.
